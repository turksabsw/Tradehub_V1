## KRITIK NOT: Frappe Rating Fieldtype Davranışı

Frappe `Rating` fieldtype'ı dahili olarak **0 ile 1 arası bir ondalık sayı** saklar:

| Kullanıcı Görünümü | DB Değeri | Hesaplama |
|---------------------|-----------|-----------|
| 1 yıldız (★☆☆☆☆) | 0.2 | 1/5 = 0.2 |
| 2 yıldız (★★☆☆☆) | 0.4 | 2/5 = 0.4 |
| 3 yıldız (★★★☆☆) | 0.6 | 3/5 = 0.6 |
| 4 yıldız (★★★★☆) | 0.8 | 4/5 = 0.8 |
| 5 yıldız (★★★★★) | 1.0 | 5/5 = 1.0 |

Bu nedenle:
- **Mevcut Int 1-5 alanlar** → Rating'e dönüştürüldüğünde **veri migration** gerekir: `new_value = old_int_value / 5.0`
- **Hesaplanan 0-100 Float alanlar** → Rating'e dönüştürülMEMELİ (range uyumsuz)
- **Ağırlık/config Float alanlar** → Rating'e dönüştürülMEMELİ

### Toplu Migration Patch (Python)

```python
# tradehub_compliance/patches/convert_review_int_ratings_to_rating.py
import frappe

def execute():
    """Convert Review sub-rating Int fields (1-5) to Rating fraction (0-1)."""
    rating_fields = [
        'product_quality_rating',
        'value_for_money_rating',
        'shipping_rating',
        'seller_communication_rating',
        'accuracy_rating'
    ]

    for field in rating_fields:
        # Int 1-5 → Rating 0.2-1.0 (divide by 5)
        frappe.db.sql(f"""
            UPDATE `tabReview`
            SET `{field}` = `{field}` / 5.0
            WHERE `{field}` > 1
        """)

        # Int 1 → Rating 0.2
        frappe.db.sql(f"""
            UPDATE `tabReview`
            SET `{field}` = 0.2
            WHERE `{field}` = 1
        """)

    frappe.db.commit()
    print("✓ Review sub-ratings converted from Int (1-5) to Rating (0.2-1.0)")
```

// tradehub_catalog/doctype/ranking_weight_config/ranking_weight_config.js
frappe.ui.form.on('Ranking Weight Config', {
    validate: function(frm) {
        const weight_fields = [
            'sales_weight', 'view_weight', 'conversion_weight', 'ctr_weight',
            'wishlist_weight', 'review_weight', 'rating_weight',
            'quality_score_weight', 'seller_score_weight',
            'recency_weight', 'stock_weight'
        ];

        // Her ağırlık 0-100 arasında olmalı
        weight_fields.forEach(field => {
            let val = frm.doc[field] || 0;
            if (val < 0 || val > 100) {
                frappe.throw(__(`${frappe.meta.get_label('Ranking Weight Config', field)} must be between 0 and 100`));
            }
        });

        // Toplam ağırlık 100 olmalı (opsiyonel uyarı)
        let total = weight_fields.reduce((sum, f) => sum + (frm.doc[f] || 0), 0);
        if (total !== 100) {
            frappe.msgprint({
                title: __('Weight Total Warning'),
                message: __(`Total weights sum to ${total}. Recommended total is 100.`),
                indicator: 'orange'
            });
        }

        // Penalty alanları negatif olmalı
        if (frm.doc.out_of_stock_penalty > 0) {
            frappe.throw(__('Out of Stock Penalty should be 0 or negative'));
        }
        if (frm.doc.low_rating_penalty > 0) {
            frappe.throw(__('Low Rating Penalty should be 0 or negative'));
        }
    }
});
```

# tradehub_seller/doctype/seller_score/seller_score.py
def validate(self):
    weight_fields = [
        'fulfillment_weight', 'delivery_weight', 'quality_weight',
        'service_weight', 'compliance_weight', 'engagement_weight'
    ]

    for field in weight_fields:
        val = self.get(field) or 0
        if val < 0 or val > 100:
            frappe.throw(f"{self.meta.get_label(field)} must be between 0 and 100")

    total = sum(self.get(f) or 0 for f in weight_fields)
    if abs(total - 100) > 0.1:
        frappe.msgprint(f"Warning: Score weights sum to {total}%. Recommended total is 100%.")
```

## 5. Bağımlılıklar ve Riskler

### 5.1 Veri Migration Riskleri

| Risk | Etki | Önlem |
|------|------|-------|
| **Mevcut Int verileri kaybolabilir** | Yüksek | Migration patch'i `bench migrate`'den ÖNCE çalıştırılmalı |
| **0 değerli Int alanlar** | Düşük | `WHERE > 0` koşulu ile sadece dolu alanlar dönüştürülür |
| **Çift çalıştırma** | Orta | Patch idempotent olmalı — `WHERE > 1` koşulu ile zaten dönüştürülmüş veriler atlanır |
| **DB sütun tipi değişikliği** | Düşük | Int→Float (Rating) MariaDB'de sorunsuz dönüşür |

### 5.2 Uygulama Sırası

```
1. Veritabanı backup al
2. review.json'daki 5 alanın fieldtype'ını Int→Rating olarak değiştir
3. Migration patch dosyasını oluştur
4. patches.txt'ye patch satırını ekle
5. bench migrate çalıştır (sıra: patch → schema değişikliği)
6. bench build çalıştır (frontend güncelleme)
7. bench clear-cache çalıştır
8. Sonuçları doğrula
```

def execute():
    rating_fields = [
        'product_quality_rating', 'value_for_money_rating',
        'shipping_rating', 'seller_communication_rating', 'accuracy_rating'
    ]
    for field in rating_fields:
        frappe.db.sql(f"""
            UPDATE `tabReview`
            SET `{field}` = ROUND(`{field}` * 5)
            WHERE `{field}` > 0 AND `{field}` <= 1
        """)
    frappe.db.commit()
